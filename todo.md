# Next.js App Router Migration Checklist

- [x] Inventory existing Vite routes, approved content sources, images, SEO tags, schemas, and crawl files.
- [x] Capture the existing URL map and identify any legacy path redirects required to preserve search equity.
- [x] Replace the Vite application entry points with a Next.js App Router configuration that supports static generation.
- [x] Configure and verify the approved compatibility static-build path for the Next.js export.
- [x] Recreate the shared layout, navigation, footer, fonts, design tokens, mobile navigation, and reusable UI components in the App Router.
- [x] Migrate the homepage, core marketing pages, service templates, location templates, blog routes, legal pages, and 404 page.
- [x] Implement route-level metadata, canonical URLs, Open Graph data, JSON-LD, robots directives, and XML sitemap generation.
- [x] Verify all approved text is retained verbatim and all image references remain deployment-safe.
- [x] Validate production static build output, route parity, internal links, structured data, responsive layouts, and redirect behavior.
- [ ] Create a final checkpoint and provide publish instructions after validation is complete.
